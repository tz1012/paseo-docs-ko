# 왜 파세오인가?

Paseo는 코딩 에이전트를 실행하고 조정하기 위한 자체 호스팅 플랫폼입니다. 이미 보유하고 있는 하드웨어에서 이미 사용하고 있는 에이전트 CLI를 실행하고 어디에서나 이를 구동할 수 있는 UI, CLI 및 API를 제공합니다.

## 아키텍처

- 데몬 클라이언트 아키텍처. 데몬은 에이전트를 관리합니다. 클라이언트(모바일, 데스크톱, 웹, CLI)는 로컬로 또는 릴레이를 통해 연결됩니다. 원격 액세스는 추가 기능이 아닙니다.
- macOS, Windows, Linux는 모두 주요 대상입니다. 그들 중 어느 것도 항구나 나중에 생각한 것이 아닙니다.
- 모바일, 데스크톱, 웹은 별도의 기본 클라이언트입니다. 모바일 앱은 웹뷰가 아닌 React Native로 제작되었습니다.

## 제공자

- 직접 가져오세요. Claude 구독, OpenAI 계정, 자체 API 키, 자체 호스팅 엔드포인트를 사용하세요. Paseo는 모델 호출을 프록시하지 않습니다.
- 로컬 음성 스택. 음성-텍스트 및 텍스트-음성 변환은 기본적으로 기기 내에서 실행됩니다. 클라우드 품질을 원하는 경우 OpenAI 공급자를 구성할 수 있습니다.
- 오픈 소스. 코드에 원격 분석이 없습니다.

## 에이전트가 실행되는 곳

- 노트북, 홈랩, 회사 서버. 동일한 데몬, 동일한 클라이언트 표면.
- git이든 아니든 모든 디렉터리. 에이전트를 실행하고, 로컬로 병합하고, 앱에서 차이점을 검토하세요.
- GitHub PR, 확인 및 리뷰는 원할 때 앱에 표시됩니다. 필요하지 않습니다.

## 병렬 작업

- 분할 및 창. 에이전트, 터미널, 브라우저가 하나의 작업 공간에 나란히 있습니다.
- 작업 트리별 서비스. 각 작업 트리는 충돌하지 않도록 `web.fix-auth.my-app.localhost`과 같은 프록시 URL을 통해 연결할 수 있는 개발 서버 및 데이터베이스용 포트를 할당받습니다.
- 작업 트리를 통해 동일한 저장소에 있는 여러 에이전트.

## 자동화

- CLI는 앱과 동일한 표면을 노출합니다. UI의 모든 내용은 스크립트 가능합니다.
- [Paseo 도구](/docs/orchestration). 에이전트는 Paseo를 직접 구동할 수 있습니다. 격리된 작업 공간을 만들고, 하위 에이전트를 생성하고, 터미널을 열고, 프롬프트를 보낼 수 있습니다.
- [허브](/docs/hub). 누군가 GitHub, Slack 또는 Discord에서 귀하를 언급할 때 데몬에서 에이전트를 시작하는 귀하가 호스팅하는 서비스입니다.

## 그게 아닌데

호스팅된 에이전트도 아니고 IDE도 아니고 모델 공급자도 아닙니다. Paseo는 이미 사용하고 있는 CLI를 실행하고 방해가 되지 않습니다.
