# 브라우저 자동화

Paseo의 에이전트는 Paseo 데스크톱 앱에서 볼 수 있는 것과 동일한 탭인 실제 브라우저 탭을 구동할 수 있습니다. 에이전트는 컴퓨터를 떠나지 않고도 개발 서버를 열고, 페이지를 읽고, 흐름을 클릭하고, 양식을 작성하고, 스크린샷을 찍을 수 있습니다.

이렇게 하면 프런트엔드 작업의 루프가 닫힙니다. "변경 사항이 작동해야 합니다"라고 말하는 대신 상담원이 페이지를 열고 확인합니다.

일반적인 용도:

- **자체 변경 사항을 확인합니다.** 구성 요소를 편집한 후 에이전트는 개발 서버를 열고 페이지의 스냅샷을 찍은 후 새 텍스트나 레이아웃이 실제로 있는지 확인합니다.
- **버그 재현 및 진단.** 버그 보고서에서 정확한 순서를 클릭한 다음 콘솔 및 네트워크 로그를 읽어보세요.
- **전체 흐름을 연습합니다.** 양식, 다단계 마법사, 마우스 오버 메뉴, 드래그 앤 드롭, 파일 업로드.
- **로그인된 세션에서 작업합니다.** 탭은 세션 상태를 유지합니다. 한 번만 로그인하면 상담원이 로그인 뒤에 작업을 수행할 수 있습니다.

에이전트와 브라우저를 공유하기 때문에 작동하는 모습을 지켜보고 언제든지 개입할 수 있습니다.

## 활성화 중

브라우저 도구는 기본적으로 꺼져 있습니다. 호스트별로 활성화합니다.

- **앱에서:** **설정 → 호스트 → 에이전트**를 열고 **브라우저 도구**를 켭니다.
- **`config.json`**(`~/.paseo/config.json`):

```json
{
  "daemon": {
    "browserTools": {
      "enabled": true
    }
  }
}
```

도구는 [Paseo MCP 도구 세트](/docs/mcp)의 일부이므로 상담원이 도구를 받으려면 같은 페이지에 있는 **Paseo 도구 활성화**도 켜져 있어야 합니다. 기존 에이전트는 새 도구를 선택하기 위해 다시 로드해야 할 수도 있습니다.

> 브라우저 도구를 사용하면 상담원이 로그인된 브라우저 상태를 포함하여 Paseo 브라우저 탭에 액세스하고 제어할 수 있습니다. 신뢰하는 에이전트에 대해서만 이 기능을 활성화하세요.

## 현재는 데스크톱 전용입니다.

브라우저 탭은 Paseo 데스크톱 앱에서 호스팅됩니다. 데몬 자체는 브라우저를 실행하지 않습니다. 도구 호출을 연결된 데스크톱 앱으로 라우팅하고 연결된 앱이 없으면 오류를 반환합니다. 유선 계약은 호스트 중립적이므로 나중에 다른 호스트가 동일한 도구를 사용할 수 있습니다.

## 상담원이 페이지를 보는 방법

기본 도구는 원시 HTML 대신 페이지를 접근성 트리(제목, 텍스트, 양식 상태 및 계층 구조)로 반환하는 `browser_snapshot`입니다.

```yaml
- document "Settings"
  - heading "Workspace" [level=1]
  - text: "Connected as Maya"
  - textbox "Display name" [ref=@e2]
  - button "Save changes" [ref=@e3]
```

대화형 요소는 `@e3`과 같은 참조를 전달합니다. 에이전트는 `browser_click`, `browser_fill` 및 기타 작업 도구에 참조를 전달합니다. 참조는 해당 탭의 최신 스냅샷에서 나오며 페이지가 변경되면 만료됩니다. 오래된 참조는 잘못된 요소에 대해 작동하는 대신 오류를 반환합니다.

트리가 캡처할 수 없는 모든 경우 에이전트는 `browser_screenshot`으로 대체되고 `browser_logs`은 콘솔 메시지와 네트워크 타이밍을 노출합니다.

## 아키텍처

```
agent ──MCP──▶ daemon (broker) ──▶ browser host (desktop app) ──▶ webview
```

- **작업 공간 범위 탭.** 상담원은 자신의 작업 공간에 있는 탭만 보고 제어합니다. 집중을 방해하지 않고 백그라운드에서 새 탭이 열립니다.
- **탭에서 호스트로의 라우팅.** 데몬은 각 탭을 소유한 호스트를 기억하고 거기에 탭 명령을 라우팅합니다. `browser_list_tabs`은 연결된 모든 호스트를 집계합니다.
- **신뢰할 수 있는 입력.** 클릭, 키, 마우스 오버 및 드래그는 실제 브라우저 입력 이벤트로 전달됩니다. CSS `:hover` 트리거이며 페이지는 에이전트의 클릭과 사용자의 클릭을 구분할 수 없습니다. 모든 작업은 먼저 대상이 표시되고, 활성화되고, 안정적일 때까지 기다립니다.
- **대화상자는 절대 차단되지 않습니다.** `alert`이 허용됩니다. `confirm`, `prompt` 및 `beforeunload`은 무시됩니다. 처리된 모든 대화는 도구 결과에 보고되므로 에이전트는 변경된 페이지 흐름을 알 수 있습니다.

## 보안

- 탐색은 `http(s)` URL로 제한됩니다.
- 파일 업로드는 상담원 작업공간 내부의 파일만 참조할 수 있습니다.
- 탭은 쿠키 및 로그인을 포함하여 Paseo에서 사용하는 브라우저 프로필을 공유합니다. 이것이 로그인 테스트가 작동하는 이유이며 이 기능이 호스트별로 선택되는 이유입니다.

전체 도구 목록은 [도구 참조](/docs/browser-tools)를 확인하세요.
