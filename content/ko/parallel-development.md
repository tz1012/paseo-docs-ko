# 병렬 작업 실행

Paseo 데스크톱 앱을 사용해 여러 코딩 에이전트에 독립적인 작업을 맡기고, 변경 사항을 검토하고, 결과를 실행하세요. 각 작업에는 자체 Git 작업 트리와 브랜치가 있는 작업공간이 제공되며 에이전트, 파일, 차이점, 터미널 및 브라우저 탭이 한곳에 모입니다.

[데스크톱 앱](/docs#desktop-app-recommended), 로컬 Git 저장소, 설치하고 인증한 [코딩 에이전트](/docs/supported-providers) 하나 이상으로 시작하세요. 아래 예시에서는 `origin/main` 브랜치가 있는 저장소를 사용합니다.

## 두 작업 시작하기

1. **새 작업공간**을 열고 프로젝트를 선택합니다.
2. **격리**를 **새 작업 트리**로 설정하고 시작 참조로 `origin/main`을 선택합니다.
3. 에이전트와 모델을 선택한 다음 작업을 제출합니다. 예: “프로젝트 목록에 필터링을 추가하세요. 관련 테스트를 실행하세요.”
4. 같은 시작 참조에서 **새 작업 트리**를 사용해 두 번째 작업공간을 만듭니다. 해당 에이전트에는 다른 작업을 맡깁니다. 예: “설정 페이지에 키보드 탐색을 추가하세요. 관련 테스트를 실행하세요.”

두 에이전트는 동시에 실행됩니다. 사이드바에서 작업공간을 선택해 진행 상황을 확인하거나 후속 작업을 보내세요. 두 작업에 같은 공급자를 사용하거나 서로 다른 공급자를 선택할 수 있습니다.

별도 작업 트리는 파일 편집 내용을 서로 다른 브랜치에 유지합니다. 같은 기능의 대안 구현 두 가지를 만들려면 두 에이전트에 같은 작업을 맡기고 결과를 비교한 뒤 하나를 선택하세요.

## 각 변경 사항 검토하기

작업공간을 선택하고 명령 센터에서 **변경 사항**을 열어 차이점을 확인하세요. 소스를 탐색하고 편집하려면 **파일**을 여세요. 분할 창을 사용하면 검토 중인 코드 옆에 에이전트 대화를 둘 수 있습니다.

해당 작업공간의 에이전트에 수정 사항을 보내세요. 다른 의견이 필요하면 같은 작업공간에서 **새 에이전트**를 사용하고 파일을 편집하지 않은 채 변경 사항을 검토하도록 요청하세요. 같은 작업공간의 에이전트들은 작업 디렉터리를 공유합니다.

## 앱 실행 및 테스트하기

선택한 작업공간의 명령 센터에서 **새 터미널**을 사용하세요. 그곳에서 종속성을 설치하고 프로젝트의 테스트 또는 개발 명령을 실행합니다.

각 작업 트리에는 자체 파일이 있지만 프로세스는 여전히 머신의 네트워크 포트를 공유합니다. 실행 중인 각 복사본에 서로 다른 개발 서버 포트를 할당하세요. 반복 가능한 설정과 서비스 포트를 구성하려면 [작업 트리 설정 및 스크립트](/docs/worktrees#paseojson)를 참조하세요.

웹 앱의 경우 **새 브라우저**를 사용하고 해당 작업공간의 개발 서버 URL을 입력하세요. 변경된 흐름을 확인한 다음 작업공간을 전환해 다른 구현을 테스트하세요. 브라우저 탭은 데스크톱 앱 안에서 실행됩니다.

에이전트에게 해당 탭에서 앱을 확인하도록 요청할 수도 있습니다. [브라우저 자동화](/docs/browser#enabling)를 활성화한 다음 확인할 URL과 구체적인 단계를 전달하세요. 예:

> http://localhost:3001을 열고 프로젝트 목록을 이름으로 필터링한 다음, 필터를 지우면 전체 목록이 복원되는지 확인하세요. 실패를 보고하고 결과의 스크린샷을 찍으세요.

## 병합할 항목 선택하기

각 작업공간의 차이점과 테스트 결과를 검토하세요. 해당 브랜치를 커밋하고 풀 리퀘스트를 열기 전에, 작업공간 터미널 또는 에이전트를 통해 평소 Git 워크플로를 사용해 남은 변경을 요청하세요.

독립적인 작업은 각 브랜치를 검토하고 병합하세요. 경쟁하는 구현은 유지할 버전을 선택하세요. 더 이상 필요하지 않은 작업공간은 보관하세요. 마지막 작업공간이 보관된 후에는 [작업 트리 정리](/docs/worktrees#manage-the-workspace)가 관리 디렉터리를 제거합니다.

## 에이전트가 작업을 조율하게 하기

에이전트가 작업공간을 만들고, 작업자를 시작하고, 결과를 수집하게 하려면 [오케스트레이션](/docs/orchestration)을 사용하세요. 작업자는 Paseo에 표시되므로 작업 중인 대화와 변경 사항을 확인할 수 있습니다.
