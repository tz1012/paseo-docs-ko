# 업데이트

Paseo는 **Stable** 및 **Beta**라는 두 가지 채널을 통해 업데이트를 제공합니다.

대부분의 릴리스는 안정 채널을 통해 출시됩니다. 베타는 모든 사람에게 출시되기 전에 다음에 나올 내용을 테스트할 수 있는 릴리스 후보입니다.

## 버전 번호

Paseo는 시험판 태그를 사용하여 [의미적 버전 관리](https://semver.org)를 따릅니다.

안정적인 릴리스는 다음과 같습니다.

```
v0.1.90
```

동일한 릴리스의 베타는 다음과 같습니다.

```
v0.1.90-beta.1
```

릴리스에 추가 테스트가 필요한 경우 추가 베타를 삭감합니다.

```
v0.1.92-beta.1
v0.1.92-beta.2
v0.1.92-beta.3
```

릴리스가 준비되면 최종 안정 태그는 `v0.1.93`이 아닌 `v0.1.92`입니다. 베타는 동일한 안정 버전으로 가는 길에 있는 체크포인트입니다.

## 안정적인 채널

안정적인 채널이 기본값입니다. 안정적인 데스크톱 릴리스는 **36시간**에 걸쳐 점진적으로 출시되므로 예상치 못한 일이 발생하더라도 한꺼번에 모든 사람에게 영향을 미치지는 않습니다. 롤아웃이 진행됨에 따라 자동 업데이트 확인이 릴리스를 선택합니다. 앱에서 **확인**을 클릭하면 출시를 우회하고 즉시 설치됩니다.

안정 릴리스는 대부분의 사용자가 실행해야 하는 것입니다.

## 베타 채널

베타 채널은 출시 지연 없이 모든 시험판이 게시되는 즉시 제공됩니다. 베타가 안정 버전으로 승격되면 베타 사용자도 즉시 안정 업데이트를 받게 됩니다.

베타는 수정 사항과 기능을 조기에 얻을 수 있는 가장 좋은 방법입니다. 버그가 발생하면 신고하세요. 베타 피드백은 안정적인 릴리스를 안정적으로 만들어줍니다.

### 베타 채널 가입 방법

데스크톱 앱에서:

1. **설정**을 엽니다.
2. **정보**로 이동합니다.
3. **출시 채널**에서 **베타**를 선택합니다.

그때부터 앱은 베타 업데이트를 확인합니다.

## 앱스토어

일반적으로 데스크탑 릴리스와 CLI가 먼저 제공됩니다. App Store 및 Play Store 출시는 검토를 거치기 때문에 지연될 수 있습니다.

현재 앱 스토어에는 베타 채널이 없습니다. 안정적인 빌드만 제출됩니다. 초기 Android 빌드를 원한다면 [GitHub 릴리스 페이지](https://github.com/getpaseo/paseo/releases)에서 APK를 다운로드하세요.

## 문제가 발생하면 어떻게 해야 하나요?

베타 빌드에는 가장자리가 거칠 것으로 예상됩니다. 베타로 인해 문제가 발생하는 경우 **설정 → 정보 → 출시 채널**에서 공개 채널로 다시 전환할 수 있습니다. 다음 안정 업데이트는 정상적으로 설치됩니다.

아직 안정 버전으로 출시되지 않은 수정 사항이 필요한 경우 베타 버전을 유지하면서 문제를 보고하세요. 베타에서 발견된 대부분의 문제는 안정 릴리스 이전에 수정되었습니다.
