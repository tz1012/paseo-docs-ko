# 호스팅 Hub

[Paseo Hub](https://hub.paseo.sh)는 관리형 서비스입니다. 로그인하거나 계정을 만들어 무료 체험을 시작하세요.

지금 시작하려면 [Hub를 직접 실행하세요](/docs/hub/self-hosting). 프로젝트, 구성, 트리거, 데몬, 활동은 두 형태 모두 같은 모델을 사용합니다. 관리형 서비스에서는 GitHub App, Slack 앱, Discord 애플리케이션을 서비스 측이 소유하고, 자체 호스팅 Hub에서는 사용자가 직접 만들고 관리하는 앱을 사용합니다.

가격과 포함된 기능은 [Hub 페이지](/hub)에서도 확인할 수 있습니다.
