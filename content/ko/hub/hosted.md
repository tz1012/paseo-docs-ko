# 호스팅 Hub

[Paseo Hub](https://hub.paseo.sh)는 관리형 서비스입니다. 계정을 만들면 조직이 Free 플랜으로 시작합니다. 좌석 1개와 월별 에이전트 실행 할당량이 제공되며, 카드가 필요 없고 만료되지 않습니다. 무제한 실행, 더 많은 좌석 또는 초대가 필요하면 Hub의 **Billing**에서 Pro로 업그레이드하세요. 현재 가격과 각 플랜의 포함 내역은 [Hub 페이지](/hub)에 있습니다.

로그인하면 [빠른 시작](/docs/hub/quickstart)에서 안내하는 것과 같은 4단계 체크리스트가 있는 **Home**이 열립니다. 앱 연결, 데몬 연결, 트리거 생성, 실행입니다.

지금 시작하려면 [Hub를 직접 실행하세요](/docs/hub/self-hosting). 프로젝트, 구성, 트리거, 데몬, 활동은 두 형태 모두 같은 모델을 사용합니다. 관리형 서비스에서는 GitHub App, Slack 앱, Discord 애플리케이션을 서비스 측이 소유하고, 자체 호스팅 Hub에서는 사용자가 직접 만들고 관리하는 앱을 사용하며 플랜이나 결제 기능은 없습니다.
