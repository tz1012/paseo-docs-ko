# 호스팅 Hub

[Paseo Hub](https://hub.paseo.sh)는 관리형 서비스입니다. 아직 일반에 공개되지 않았습니다. 기존 계정은 로그인할 수 있지만 신규 계정 등록은 닫혀 있습니다.

지금 시작하려면 [Hub를 직접 실행하세요](/docs/hub/self-hosting). 프로젝트, 구성, 트리거, 데몬, 활동은 두 형태 모두 같은 모델을 사용합니다. 관리형 서비스에서는 GitHub App, Slack 앱, Discord 애플리케이션을 서비스 측이 소유하고, 자체 호스팅 Hub에서는 사용자가 직접 만들고 관리하는 앱을 사용합니다.

호스팅 서비스 출시 소식을 받으려면 [Paseo Discord에 참여](https://discord.gg/jz8T2uahpH)하고 `#paseo-hub` 채널을 지켜보세요. 출시 소식은 그곳에 공지되므로 누구에게도 직접 메시지를 보낼 필요가 없습니다.
