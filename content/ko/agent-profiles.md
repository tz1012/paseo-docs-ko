# 에이전트 프로필

함께 사용하는 설정을 이름이 있는 프로필로 저장하세요. 에이전트를 만들 때마다 모델, 사고 수준, 모드를 각각 선택하는 대신 **UI 작업**, **계획**, **검토**를 선택할 수 있습니다.

- **사용자를 위해:** 한 번 선택하면 저장된 공급자, 모델, 모드, 사고 수준 및 사용 가능한 기능 설정이 함께 적용됩니다.
- **오케스트레이션 에이전트를 위해:** 프로필 메모는 위임 작업에 해당 설정을 언제 선택할지 설명합니다.

## 프로필 만들기

1. **설정 → 호스트 → 에이전트 → 에이전트 프로필**을 엽니다.
2. **새 프로필**을 선택하고 **UI 작업** 같은 이름을 지정합니다.
3. 공급자, 모델, 모드, 사고 수준 및 사용 가능한 기능을 선택합니다.
4. 이 프로필이 처리해야 할 작업 종류를 **사용 시점**에 입력합니다.
5. **저장**을 선택합니다.

프로필은 해당 호스트에 저장됩니다. 사용 가능한 설정은 선택한 공급자와 모델에 따라 달라집니다.

## 한 번의 선택으로 설정 적용하기

에이전트를 만들 때 모델 선택기를 열고 **프로필** 아래에서 저장된 프로필을 선택하세요. Paseo가 설정을 함께 적용하며, 프롬프트를 보내기 전에도 설정을 조정할 수 있습니다.

저장된 프로필을 변경하면 이후 선택에 영향을 줍니다. 이미 시작한 에이전트는 업데이트하지 않습니다.

## 메모로 위임 안내하기

**사용 시점** 필드는 프로필의 메모입니다. Paseo는 오케스트레이션 에이전트가 작업자를 어떻게 시작할지 선택하기 전에 메모를 읽을 수 있도록 도구를 통해 이를 제공합니다.

각 프로필에 명확한 전문 분야를 지정하세요.

| 프로필 | 메모 예시 |
| -------- | -------------------------------------------------------------------------------------------- |
| UI 작업 | 컴포넌트, 레이아웃, 스타일링 및 시각적 완성도 개선에 사용합니다. |
| 계획 | 아키텍처, 근본 원인 조사 및 구현 접근 방식 비교에 사용합니다. |
| 검토 | diff, 정확성, 누락된 테스트 및 불필요한 복잡성을 독립적으로 검토할 때 사용합니다. |

프로필마다 다른 공급자와 모델을 사용하거나, 같은 모델에 서로 다른 설정을 사용할 수 있습니다.

[Paseo 도구를 활성화](/docs/orchestration#get-started)한 뒤 다음과 같이 요청하세요.

> Paseo 프로필과 메모를 확인하세요. 설정 페이지 UI 변경에 사용할 프로필을 하나 선택한 다음, 검토 프로필로 diff를 독립적으로 검토하세요.

오케스트레이터는 프로필을 읽고 각 작업에 사용할 설정을 선택한 뒤 작업자를 시작합니다. 메모는 선택 기준입니다. 작업자에게 실제로 맡길 내용은 작업 프롬프트에 넣으세요.

번들로 제공되는 [Paseo 스킬](/docs/skills#paseo-paseo-reference)은 에이전트가 위임하기 전에 프로필과 메모를 확인하도록 안내합니다. 적합한 프로필이 없으면 구성된 공급자와 모델을 검색하고 대체 선택을 사용자에게 알리도록 지시합니다.

위임 예시는 [일반적인 워크플로](/docs/orchestration-workflows)를, 도구 인터페이스는 [MCP 참조](/docs/mcp#agent-profiles)를 확인하세요.
